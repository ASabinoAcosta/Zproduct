## ✨ Características

- 🔐 Inicio de sesión con control de horario por turno
- 📦 Catálogo de productos y movimientos recientes
- 🧾 Ventas con ITBIS y generación de facturas en PDF
- 👥 Roles de Administrador y Cajero

## 📥 Instalación (sin código)

1. Ve a la sección [**Releases**](../../releases/latest).
2. Descarga el archivo `Zproduct-win-x64.zip`.
3. Descomprímelo y abre `Zproduct.exe`.

> ⚠️ **Requisito:** tener [PostgreSQL](https://www.postgresql.org/download/) instalado.

## 🛠️ Para desarrolladores

```bash
git clone https://github.com/ASabinoAcosta/Zproduct.git
```

Abre la solución en Visual Studio con .NET 10 y ejecútala.
